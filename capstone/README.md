## Personalized requirements

- K mod 3 = 1: the assembler reports invalid instructions with their original source line number.
- K mod 4 = 2: box width = 16 × (2 + 1) = **48 pixels**.
- Box top row = **58**; height = **20 rows**.
- Three 16-bit screen words are written per row.
- First screen address = 16384 + (32 × 58) = **18240**.
- The row loop advances by 32 words: after writing 3 words, it adds 29.

## Project files

- `CPU.hdl`, `Memory.hdl`, `Computer.hdl`: Hack computer hardware.
- `assembler.py`: two-pass Hack assembler.
- `test_assembler.py`: automated unit tests for encoding, labels, variables, and error reporting.
- `Box.asm`: draws or clears the personalized box depending on the keyboard.
- `Box.hack`: machine code generated by this project's assembler.
- `REPORT-TEMPLATE.md`: report structure and screenshot checklist.

## Run the assembler

From this folder:

```bash
python assembler.py Box.asm
```

This writes `Box.hack` beside `Box.asm`.

Run the assembler unit tests:

```bash
python -m unittest -v test_assembler.py
```

For the K = 58 extra feature, test an invalid instruction. The assembler should report the original source line, for example `Line 3: invalid instruction`, rather than displaying a Python traceback.
