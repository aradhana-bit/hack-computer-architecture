## Run the assembler

From this folder:

```bash
python assembler.py Box.asm
```

This writes `Box.hack` beside `Box.asm`. To test error reporting, create a temporary assembly file containing an invalid instruction and run the assembler; it should print the original line number rather than a Python traceback.
